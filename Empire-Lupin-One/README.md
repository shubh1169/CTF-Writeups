# Empire Lupin One - Penetration Testing Lab

## Overview

Empire Lupin One is a vulnerable machine created for penetration testing practice.

## Objective

The objective of this lab was to perform reconnaissance, identify vulnerabilities, gain initial access, and perform privilege escalation.

## Platform

- VulnHub
- Kali Linux

## Tools Used

- Nmap
- Gobuster
- Netcat
- Burp Suite
- Linux enumeration tools

## Methodology

1. Information Gathering
2. Network Enumeration
3. Service Enumeration
4. Web Enumeration
5. Vulnerability Identification
6. Initial Access
7. Privilege Escalation

## Lessons Learned

This lab helped me practice network enumeration, web enumeration, vulnerability analysis, exploitation, and Linux privilege escalation.

## Disclaimer

This write-up is for educational purposes and was performed in an authorized penetration-testing lab environment.
